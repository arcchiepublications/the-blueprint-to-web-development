# Contributing

This repository is intended for learning and practice.

1. Fork the repository.
2. Create a branch for your change.
3. Keep each module focused on one responsibility.
4. Test the page in a browser after making changes.
5. Submit a pull request describing what changed and how it was tested.

For beginner exercises, try adding a course to `assets/js/data/courses.js`, changing the page theme in `assets/css/styles.css`, or adding a quiz question to `assets/js/data/quiz-questions.js`.
