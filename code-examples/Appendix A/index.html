About the academy

Learning should feel clear, useful and achievable.

Mini Learning Academy is a demonstration project created to show how core front-end web technologies can be combined to build a user-friendly educational website. It is a front-end prototype, not a production learning management system.

  • Simple navigation and accessible page structure
  • Responsive layouts for mobile, tablet and desktop
  • Interactive course discovery and learning activities
